# Warning Label for Humans: One Line, Big Laugh

The warning label every human should ship with: one line, written like a real safety label, funny first and plausible second. `main.ts` writes the line to `entry.txt`, enforcing the gates — non-empty, at most 160 characters, exactly one line and one sentence ending in a single period, no stray whitespace — then reads the file back and verifies the bytes match.

> "WARNING: This human contains no off switch, runs on caffeine and spite, and will skim the instructions, then ask how it works."

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/u-0xb3e689-warning-out node main.ts
```
